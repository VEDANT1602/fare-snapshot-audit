# Data card

The original stationary simulation has 2,400 quotes over 160 days: 1,500 training, 300 validation and 600 test quotes, split by time. Route, lead time, departure seasonality and weekend status are known at quote time. paid_fare is a later label. post_booking_fare is a separately named intentionally leaked diagnostic prohibited for serving. Quotes expire after five fixture-time units. Values are fictional fare units, not real travel prices. No booking API, consumer advice, causal pricing effect or deployment is implied.

All fixtures were generated specifically for this independent project. No upstream dataset, weights, media or result numbers were imported.
